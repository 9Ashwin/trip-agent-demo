出行需求

节奏宽松 不要剧烈运动 自然风光 人文古迹 美食为主
这套东西是怎么跑起来的？
  1. 你在左边填需求，点「开始规划」
  2. 浏览器把需求 POST 给本机后端 /api/plan
  3. 后端把需求交给大模型，同时告诉它有一个 web_search 工具可用
  4. 大模型说「我要搜：广州 昆明 机票 9月30日」
  5. 后端真的去搜，把结果塞回给大模型
  6. 循环 4–5 次，模型信息够了，开始写方案
  7. 后端用 SSE 把每一步实时推给前端，你就看到了上面的滚动过程

关键点：联网搜索发生在后端服务器，不是浏览器里。 API Key 也只存在后端，前端永远看不到 —— 这就是为什么「把 HTML 改成网页格式」并不能让它自己联网。
